aero - Fast as an arrow, light as the wind.
============================
aero is a lightweight fast window manager based heavily off DWM.


It is currently in its alpha phase and un-operational due to some bugs.<br>


Version 1 will essentially be a DWM replication (with some QOL patches built-in) however, instead of 1 large
file, it is split into many nicely packaged files.
